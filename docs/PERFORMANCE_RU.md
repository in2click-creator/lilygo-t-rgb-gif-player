# Замер производительности v1.0.2-perf

Прошейте скетч с прежними настройками T-RGB 2.1 Full Circle.
Откройте Serial Monitor на 115200, отправьте `d` и Enter.
Появится `[PERF] ON`; повторная команда выключает диагностику.
По умолчанию после перезагрузки она выключена.

Выберите свою GIF и оставьте её на 15–20 секунд. Пришлите строку `GIF: ...`
с именем и размером файла и 2–3 строки `[PERF]`. Повторите для лёгкой и
тяжёлой GIF. Смена файла обнуляет статистику; повторы одного файла её сохраняют.

Пример формата (цифры иллюстративные, не результат замера платы):

```text
[PERF] #4 fps=24.0 n=120 decode=15.20/27.00 output=2.10/3.00 ms over=4 reopen=2:6.00/7.00 ms
```

- `#4`: номер файла в отсортированном списке.
- `fps`: число выведенных кадров / фактическое время окна; включает ожидания,
  чтение и повторы. Это скорость отправки кадров, не измерение обновления LCD.
- `n`: количество выведенных GIF-кадров в этом окне.
- `decode`: среднее/максимальное время вызова декодера в миллисекундах,
  включая чтение SD, композицию/масштабирование и опрос тача внутри callbacks.
- `output`: среднее/максимальное время `pushColors`, не физическое время
  сканирования LCD-панели.
- `over`: число кадров, у которых decode + output превышает нормализованную
  задержку GIF (0 → 100 мс, 1–19 → 20 мс). Это не число потерянных кадров и
  не счётчик всех опозданий: переоткрытие и задержки планирования сюда не входят.
- `reopen`: число повторных открытий и среднее/максимальное время закрытия,
  проверки заголовка, очистки холста и открытия декодера. Первый ручной выбор
  файла сюда не входит. При 0 повторов времена также 0.

Сводка формируется после кадра, примерно каждые пять секунд. Если порт закрыт
или в передающем буфере нет места для всей строки, окно пропускается и счётчики
обнуляются, чтобы не ждать USB. Экраны статуса и пустой вызов декодера в конце
файла не считаются кадрами. На очень долгом кадре сводка появится позже.
Диагностика сама имеет небольшую стоимость; для сравнения можно отключить её
командой `d`. Пока это измерительный режим, а не ускорение проигрывателя.

Статус: расчёты проверяются host-тестом, сборка — CI; реальные значения с платы
ещё предстоит получить. Результаты проверки v1.0.1 не являются проверкой
этой диагностической версии.
