# Проверка v1.0.1-test на LILYGO

Плата: **T-RGB 2.1 Full Circle**, ESP32-S3, 16 MB flash, 8 MB OPI PSRAM.
Статус: **ожидает проверки владельцем на устройстве**.

## Прошивка

1. Скачайте ZIP исходников ветки исправления и распакуйте целиком в новую папку.
2. Откройте `LilyGo_GifPlayer/LilyGo_GifPlayer.ino` в Arduino IDE.
3. Используйте версии библиотек и параметры из `README_RU.md`:
   esp32 2.0.17, LilyGo-T-RGB 1.0.5, SensorLib 0.2.3, lvgl 8.3.11,
   **OPI PSRAM**, flash 16 MB, раздел `16M Flash (3MB APP/9.9MB FATFS)`.
4. Загрузите скетч. Откройте монитор порта на 115200 и нажмите RST.
   В начале должна появиться строка `LILYGO GIF PLAYER v1.0.1-test`.

CI также собирает бинарники в `esp32s3-build-output`. Для этой проверки
проще загрузить скетч через Arduino IDE: отдельный `.bin` не содержит
инструкций о необходимых смещениях и остальных образах.

## Тестовые GIF

Из успешного Actions-запуска для этой ветки скачайте артефакт
`lilygo-device-check`. Внутри найдите `tests/fixtures/device/gif`.
Скопируйте три файла в `/gif` на FAT32 microSD, сохранив свои файлы.
Вставляйте карту при выключенном питании. Файлы также можно сгенерировать
командой `python tests/test_regressions.py` после сборки тестового стенда.

| Файл | Что должно произойти |
|---|---|
| `001-normal.gif` | По кругу меняются красный, зелёный, синий и жёлтый кадры. |
| `002-trailing-comment.gif` | Та же анимация, без дополнительной паузы на жёлтом кадре перед красным. |
| `003-invalid-lzw.gif` | Экран `GIF DECODE ERROR`; устройство не перезагружается, свайп позволяет уйти на другой файл. |

Повреждённый файл проверяйте только после загрузки исправленной версии.
Сумма заданных задержек цветных кадров — 500 мс. Фактическое время на плате
может быть больше из-за чтения, декодирования и вывода; это не обещание FPS.

## Последовательность

- [ ] Версия в Serial: `v1.0.1-test`.
- [ ] Оба цветных GIF повторяются; второй не получает отдельной паузы на стыке.
- [ ] Повреждённый GIF показывает ошибку, без сброса или зависания.
- [ ] С повреждённого файла можно уйти свайпом и командой `n`/`p` в Serial.
- [ ] Свайпы в обе стороны и переход между первым и последним файлами работают.
- [ ] Собственные GIF воспроизводятся, цвета и ориентация не изменились.
- [ ] Несколько минут повторов и переключений проходят без перезагрузки.

## Отчёт после проверки

Запишите SHA коммита или ссылку на Actions-запуск, строку версии, результат
каждого пункта и приложите Serial-лог. Для заметного рывка полезно короткое видео
обоих цветных файлов. До получения этого отчёта проверка на устройстве остаётся
незавершённой; успешная сборка в CI её не заменяет.
